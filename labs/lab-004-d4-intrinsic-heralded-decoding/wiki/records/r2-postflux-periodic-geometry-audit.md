# R2 post-flux geometry remediation audit

Date: 2026-08-28

## Defect found during integration

The original bounded adapter test applied each printed row and rotation to a chosen blue or green center and therefore verified its own coordinate convention. It did not establish that arbitrary physical/MWPM-correction strings were covered. The first matched integration diagnostic produced valid mirrored configurations absent from the 21 canonical rotations. Adding reflected rows is not a valid repair: some reflected masks coincide while requiring different entangled-neighbor pairs.

The earlier claim that 42 colour/row/rotation branches closed the production geometry gate is therefore withdrawn. Those branches remain useful tests of the printed diagrams, not evidence of a complete inference rule.

## Source-controlled replacement

Appendix A supplies the required global statement directly: for each connected component in the union of the physical error and correction X strings, there are two parity constraints, one blue and one green. Production now constructs that invariant without assigning an unprinted local row:

1. form connected components of the Boolean physical/correction union;
2. project each component onto its blue and green vertices;
3. connect same-colour vertices by every two-step union path through an opposite-colour center; and
4. verify that each non-singleton colour projection is connected.

Singleton colour projections are retained explicitly even though they have no relation edge; their even-parity constraint forces a vacuum outcome. The downstream effective-string builder now accepts this explicit active set.

## Verification

- a doubled single edge produces two active singleton colour components and no invented relation edge;
- a bounded multi-edge component produces exactly one DSU component per represented colour;
- 32 fixed physical-error seeds at paper `L=2` exercise both unit-weight and heralded first-stage MWPM branches, and every homologically trivial output reproduces exactly the union component's two colour projections; and
- malformed edge arrays and disconnected projected relations fail closed.

The full Lab 004 suite passes: **64 tests**.

## Boundary of the result

This remediates the production relation geometry before end-to-end integration. The printed local-row adapter remains executable only for source-diagram fixtures. No LER data existed, so no numerical result was retained or rerun. A matched physical-error-to-final-decision record remains the next gate.
