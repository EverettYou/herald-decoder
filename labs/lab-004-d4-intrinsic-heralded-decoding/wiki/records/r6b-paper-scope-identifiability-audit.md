# R6B paper-normalized public parity-scope identifiability

## Registered matrix

The confirmatory run uses fresh seed 20260830 on the 24-vertex, 36-edge paper-normalized L=2 graph. It exactly enumerates every edge assignment compatible with 1000 public degree records across p=[0.05, 0.1, 0.2, 0.35, 0.5]; 0 records hit the assignment cap.

All 12 isolated-hex controls pass. The matrix contains 9 fully enumerated public records with more than one nonwinding parity-scope signature.

## Decision

H_unique is **rejected**. At least one fully enumerated public record has multiple exact compatible nonwinding parity-scope signatures.

This rejects a single parity-scope list derived only from the public flux and measured-support record. It does not reject an exact fixed graph whose factors also contain latent edge or connectivity variables; that richer construction is the next scientific gate.

## Claim boundary

Finite paper-normalized L=2 structural identifiability test only. Ambiguity rejects a single observation-only charge-scope list, but does not reject a fixed factor graph with latent edge/connectivity variables and is not a BP or logical-performance result.
