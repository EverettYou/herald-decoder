# R4.5c corrected branch-resolved sequential-policy method

**Status:** registered 2026-08-29; not implemented; no policy risk computed.

## Scientific question retained

R4.5c does not change the question posed by R4.5. On the exact primitive D4 ensemble it compares four policies at both the O0 and O2 observation levels: the public fixed two-stage decoder, the public first action followed by an exact continuation, the R4.4 myopic first action followed by an exact continuation, and the future-aware exact policy. The first action ranges over all 32 syndrome-faithful red-X corrections. A winding physical-error/correction union is an immediate terminal loss. On surviving branches, the second charge record has likelihood

`P(Y=y | E,A) = 2^(C-N)`

on its affine even-parity support, where `N` is the number of active stars and `C` is the number of independent relation components. The exact second action remains the `4 x 4` product of blue and green charge-chain homology classes.

The earlier preflight established the channel counts and resource envelope but correctly stopped because endpoint-only charge relations erase parallel periodic branches. R4.5a and R4.5b have now supplied the missing branch-labelled relation topology, the linear period-cochain homology map, and a topology-faithful expanded PyMatching adapter.

## Corrected representation

Every post-flux relation is reconstructed from its actual two-step union path and carries one stable physical branch id. For a supported second record `Y`, a deterministic effective-Z branch chain is built using a spanning forest ordered by stable branch id. This representative is only a computational convention; it is not allowed to choose the logical sector.

That requirement is tested algebraically before any posterior risk is computed. For each nonterminal hidden `(E,A)` state and colour, form the relation-subgraph incidence map `H_rel` and the two-bit period cochain `W_rel`. R4.5c requires

`W_rel c = 0  for every c in ker(H_rel)`.

Two branch chains with the same boundary differ by an element of `ker(H_rel)`. Therefore this condition proves that all representatives compatible with the same `Y` have the same homology. The constructed representative must also reproduce `Y` as its boundary. A nontrivial kernel winding or a boundary mismatch is a scientifically meaningful failure: the second record would not determine the claimed homology, so the policy risk must remain censored.

Exact loss uses the validated linear `branch_chain_sector` period cochain. The older component-level Boolean winding collector is prohibited because it disagrees on 107 of 512 branched or multicycle closed chains per colour. The public second-stage decoder uses the verified private-auxiliary expanded PyMatching graph at unit physical-branch weights; its returned fault ids must form a complete primitive branch chain belonging to the exhaustive affine action set.

## Preflight and stop rules

Before policy computation, one bounded preflight must reproduce the original channel normalization, anti-leak checks, 120,320 terminal and 6,816 nonterminal hidden pairs, and 2,320,936 streamed second-record contributions. It must additionally pass unique branch provenance, endpoint-projection equivalence, the relation-cycle-kernel invariance theorem above, supported-record boundary equality, four equal homology sectors per colour, expanded-decoder affine-chain membership, and the observation-only policy-key audit.

The preflight may use no new stochastic samples or lattice sizes, at most one million representative/kernel checks, ten minutes for structural preflight, thirty minutes total projected computation, 4 GiB resident memory, and 120 million streamed contributions. Any failed gate stops the branch before final policy computation and preserves a witness. This registration tick ends without implementing the adapter or calculating risk.

### Recorded resource-projection amendment

The first implementation attempt passed every scientific and structural gate but failed a wall-time projection of 2176.8 seconds. That projection incorrectly multiplied the complete one-time branch-representative precompute by both the O2/O0 observation-multiplicity ratio and four priors. The registered implementation caches each hidden `(E,A,Y)` transition loss before observation and prior aggregation, so those representatives are not rebuilt for each O2 occurrence or prior. The failed result is preserved as `manifests/r4-corrected-sequential-policy-preflight-failed-overcounted-resource-projection-2026-08-29.json`.

The corrected resource projection adds one measured corrected branch/channel precompute to the source-frozen original R4.5 conservative four-prior streaming projection. The thirty-minute and 4-GiB limits are unchanged. This amendment changes only the accounting of reusable computation; it does not alter channel support, homology, decoder actions, validation criteria, or any scientific result.
