# R3.3 component-auxiliary fusion MILP audit

## Structural fusion encoding

R3.3 replaces fusion no-good cuts with one binary auxiliary for each source-backed isolated homologically trivial loop in the bounded graph. Each auxiliary is activated if and only if every loop edge is selected and every external edge incident on the loop is absent. A charge-parity violation fixes that loop auxiliary to zero, making the incompatible component infeasible.

The same auxiliary supplies the Appendix-A constraint count in the objective. Each active trivial loop contributes two independent parity constraints—one blue and one green—so its objective coefficient is `-2` in negative log2 probability. The fixed measured-internal count contributes the complementary constant.

## Exact fixture matrix

The primitive 12-edge graph has four catalogued isolated trivial loops. On the four-explanation MAP fixture, R3.3 exactly reproduces the low-p optimizer set `{73,82,268}`, the high-p optimizer `{279}`, and all four relative-sector optima from R3.0/R3.1.

On loop mask 238, six internal measurements and two active fusion constraints give `log2 P(s|E)=2-6=-4`. The component-auxiliary MILP objective and unique optimizer exactly match exhaustive enumeration.

Three additional tests bring the complete Lab suite to 84 passing tests.

## Remaining boundary

There are no fusion truth-table no-good cuts in R3.3. However, the finite loop catalog is itself generated by bounded enumeration, and generic winding-sector feasibility is not yet encoded structurally. Before increasing graph size, replace catalog discovery with a geometry-derived loop/component generator and encode or explicitly parameterize winding-sector likelihood constraints. R4 posterior-sector summation remains distinct.
