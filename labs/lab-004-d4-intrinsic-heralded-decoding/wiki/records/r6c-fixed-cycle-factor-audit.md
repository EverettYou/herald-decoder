# R6C fixed cycle-activation factor audit

## Exactness

The fixed cycle-factor graph matches all 49855 primitive compatible pairs with 0 mismatches. It also matches all 120 even/parity-violation probes drawn from the 9 R6B paper-L2 ambiguity records, again with 0 mismatches.

Each factor is fixed by lattice geometry. It activates from latent cycle and boundary edge bits and then evaluates the public charge parity; no candidate component label or simulator truth is supplied as decoder input.

## Scaling boundary

The primitive catalog contains 4 trivial cycles. The paper-normalized L=2 catalog already contains 1068 cycles, with edge scopes as large as 36 plus up to 11 charge bits per colour. Exactness therefore supplies a finite-graph control, not a scalable BP construction. A local connectivity-auxiliary compression is the next gate.

## Claim boundary

Exact fixed finite-graph likelihood representation on the registered primitive complete matrix and stored paper-L2 ambiguity probes only. The 1068-cycle paper catalog is not a scalable decoder result; BP, logical performance, convergence, threshold, and fault tolerance remain untested.
