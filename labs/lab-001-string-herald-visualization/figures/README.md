# Figures

`seed1-herald-ablation.svg` is generated by `../scripts/render_herald_ablation.py` and is the report's sole static configuration figure. It compares the same square (L=9), seed-1 error string with (q=1) and (q=0.75).

`string-herald-sample.html` is the unified interactive Results viewer served by the dashboard. `Square` and `Honeycomb` are lattice choices inside one generator; both share `p`, `p_m`, `q`, `p_h`, `L`, and Decoder On/Off controls. The default size is `L=9`.

The desktop viewer uses the shared Lab artifact header and a two-column workbench: the large lattice visualization and compact legend occupy the left side, while all controls are grouped into a vertical panel on the right. The common control order is lattice, tuning parameters, decoder, measurement errors, and random seed. It collapses to a stacked layout on narrow screens.

The viewer exposes its 32-bit random seed in an editable field. Reusing a seed reproduces a configuration, while the adjacent refresh button samples and displays a new seed.

The herald is sampled only at vertices with at least two incident error bonds. Since syndrome is odd parity, degree-three vertices may show both the herald and syndrome markers.

Stage 1 is executed only by the Lab-owned `scripts/local_decoder.py`: distance-one herald pairs, then syndrome–herald–syndrome, then distance-two herald pairs. The viewer sends the graph and observed messages to `predecode_payload`; it does not duplicate these rules. Stage 2 forgets every remaining herald and sends only the Stage 1 residual syndrome through the dashboard transport to the Lab-owned `scripts/mwpm_decoder.py`.

Decoder On defaults to `Combined`; `Stage 1` and `Stage 2` can be selected separately. Stage 1 can show unresolved heralds. Stage 2 and Combined show no heralds. Decoder Off restores the original configuration.

In model coordinates both lattice choices use smooth boundaries at the top and bottom and open rough plaquettes at the left and right. The outward edge of an open rough plaquette is not drawn or sampled. Its outer vertices have no stabilizer and do not appear as syndrome or herald sites; retained edges from those vertices to interior detectors become singleton PyMatching columns. The viewer rotates both lattices by 90 degrees, placing rough boundaries at the top and bottom and smooth boundaries at the left and right. Honeycomb therefore uses the wider page footprint, with its actual armchair contours visible at the sides. No boundary labels or thick boundary guides are drawn. The horizontal dashed logical cut extends beyond both smooth boundaries. The live logical-error flag is the mod-two residual-error parity on the retained data edges crossed by this path.

The lattice canvas carries a compact in-plot overlay for current-view error density, syndrome density, visible-herald density, and logical parity, leaving the narrow right-hand panel for controls only. Decoder Off uses the sampled error; Stage 1 uses the predecoding residual; Stage 2 and Combined use the final residual.

For both lattices, `p_m` changes the displayed syndrome bits without adding an auxiliary error marker, and `p_h` removes sampled heralds without adding an auxiliary loss marker. Both measurement-error parameters default to zero.

Inside the fixed Results canvas, vertex markers, syndrome disks, herald diamonds, and bond strokes scale with the fitted nearest-neighbor spacing as `L` grows. The legend remains fixed-size for readability.
