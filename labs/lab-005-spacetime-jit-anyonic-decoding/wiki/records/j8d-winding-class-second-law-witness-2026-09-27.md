## Summary

For one pre-cost-selected positive-first-mass private red-X error in each of the three new L=2 winding classes, the exact complete second public record has the same conditional law as the matched base under both frozen relation-free actions. This closes six selected representative/action contrasts, not all 54 new supports or the full physical channel.

## Evidence

The [prospective contract](../../manifests/j8d-winding-class-second-law-witness-2026-09-27.json) freezes the representative rule using only the [earlier first-mass/cost matrix](j8c-support-geometry-cost-matrix-2026-09-27.md): minimum projected first-projector terms within each winding class, with a lexicographic loop-edge tie-break. The classes `(1,-1)`, `(1,0)` and `(0,1)` have selected first masses `1/16`, `1/16` and `1/256`; the base mass is `1/4`. All four private errors retain the same complete first public flux and the same selected all-zero first charge record. Each is crossed with public actions `[0]` and `[1,30,32,34,35]` on the same ideal L=2 orbit.

The [machine result](../../results/j8d-winding-class-second-law-witness-2026-09-27.json) contains eight normalized complete second-public-law cells and all six exact candidate/base total-variation values are zero. Under the first action each law has two equally likely complete public outcomes; under the second each has 32. All 22 eligible second sites were audited per cell, including deterministic bits. Both base laws exactly replay the prior complete-law control. The calculation used 292 first and 1,212 second orbit moments plus 1,726 algebraic relation probes, within the registered caps. No histories, schedule arms, bootstrap replicates, logical scores or new dependencies ran.

## Status

The result is a finite representative null conditional on one complete first record, two fixed actions, and one ideal orbit. Other members of every winding class remain untested for their second law. Since selected-first probabilities differ, this null does not erase potential first-record information. A separate prospective cost matrix is required to decide whether an all-remaining-support exact second-law test is affordable. Neither a full-IID information null nor an unconditional logical-risk, noisy JIT, larger-geometry or threshold claim follows. L=3 still lacks its own operator orbit and sequential instrument.
