## Summary

Within the frozen periodic L=2 D4 geometry, fixing the singleton public charge action and preserving the five-edge action set leaves only the identity color-preserving red-edge graph automorphism. Consequently this restricted spatial-symmetry route offers no nontrivial map for reusing the evaluated signed-character laws in another sector. It does not rule out a nonspatial algebraic reduction.

## Evidence

The [prospective contract](../../manifests/j9c-action-preserving-spatial-map-2026-09-28.json) requires enumeration of blue/green-color-preserving red-edge maps under both public actions, then 12-face, 108-qubit and all 36-star outer-X/CZ/triangle-Z geometry checks before any held-out full-public-law replay. The [machine result](../../results/j9c-action-preserving-spatial-map-2026-09-28.json) visits 24 backtracking nodes and finds one colored action-preserving graph map: identity. It passes the full operator-geometry gates and replays all 48 stored J8X laws exactly. A separate read-only graph-isomorphism check also counts one map with the same vertex-color and action-edge labels. No new Born terms, histories, schedule arms, bootstraps or dependencies were used; the production calculation took `0.014299` CPU seconds.

The first pre-data invocation stopped at a schema assertion because J6L's Lab 004 flux-boundary vertex labels differ from the kagome star-center labels needed for an operator map. No map was enumerated and no result file was written. The [amended contract](../../manifests/j9c-action-preserving-spatial-map-2026-09-28.json) records that correction and the withdrawn runner hash; the final runner derives red-edge adjacency from the pinned red physical-qubit star endpoints. Scientific question, actions, cap and acceptance were unchanged.

## Status

The registered spatial-map prerequisite is closed. With these *two fixed public actions* and this color-preserving spatial family, there is no nonidentity candidate to validate; the 48-law identity replay is an integrity control, not a cross-sector transfer result. Other action choices, color-changing maps, nonspatial operator identities, other first records and errors, full-IID information/risk and noisy JIT remain untested. A subsequent bounded nonspatial character-reduction feasibility gate would be a separate question, not a reinterpretation of this null.
