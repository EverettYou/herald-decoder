# E1 repeated D4 projector-instrument matrix registration

Date: 2026-08-29

## Outcome

The research workflow resumes at the physical-observation gate and registers
three small diagnostics together. They are not alternatives requiring a human
ranking:

1. **E1A** checks causal hidden projector state update and the perfect E0 limit.
2. **E1B** applies false-negative/false-positive classical reporting only after
   that state update and retains multi-label reports without binary coercion.
3. **E1C** reproduces Jing *et al.*'s five-star quasi-stabilizer false-negative
   example as a localized source fixture, not a general memoryless channel.

The distinction matters physically. A wrong classical report need not change
the post-projector quantum state, whereas a quasi-stabilizer false negative can
be accompanied by intermediate-anyon fluctuations. Treating both as the same
confusion matrix would erase the time-like heralding mechanism the source is
trying to expose.

## Budget and stop rule

The matrix uses existing paper-L=2 fixtures, at most five rounds, deterministic
cases only, and less than five CPU minutes/1 GiB. It produces no Monte Carlo or
performance evidence. If a noisy record cannot map to the current binary
spatial-policy API, the implementation must retain a typed pre-translation
record and report the gap rather than silently discard labels.

## Claim boundary

Passing the matrix would establish only a source-bounded phenomenological
projector instrument and its software invariants. It would not establish an
ancilla extraction circuit, circuit-level fault tolerance, schedule advantage,
LER, a threshold, or hardware feasibility.
