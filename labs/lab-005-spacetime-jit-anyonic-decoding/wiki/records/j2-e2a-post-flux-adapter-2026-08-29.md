# J2 E2A action-bound post-flux adapter

E2A is verified for the deterministic paper-\(L=2\) boundary. The new public
adapter accepts a typed charge/vacuum report only when it is bound to the exact
stage-1 flux action. It combines that report with an explicitly supplied
physical measurement layout and produces the existing post-flux observation
whose digest covers request, action, round, layout, and sparse binary outcomes.

The adapted perfect fixture is identical to a manually constructed E0
observation and produces a valid public charge action. Wrong action binding,
flux or simultaneous labels in the post-action report, report/layout mismatch,
and a report predating the flux action all fail closed. The adapter signature
contains no hidden state, true label, physical error, future record, or logical
outcome.

All four new E2A tests pass, all 24 projector-instrument tests pass, and the
complete Lab 005 suite passes 125/125. No samples were generated.

This verifies only the shared post-flux translation prerequisite. The
two-mode/four-schedule completion matrix, stochastic history, logical scoring,
schedule advantage, threshold, and fault tolerance remain unverified.
