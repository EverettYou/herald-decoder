# Figures

`fusion-belief-matching.html` is the interactive U(1)/SU(2)/SU(3)
representation-resolved decoder workbench. Its live payload is generated by
`scripts/artifact_backend.py` using the cached/preallocated A1 Numba BP
decoder and posterior-LLR PyMatching.

`a8-full-record-ler-overview.png` is the canonical six-panel LER figure, regenerated from audited counts by `scripts/render_a8_ler_overview.py`. It replaces the six standalone LER PNGs. The six `*-nonconvergence.png` companion diagnostics remain available.

The three `a9-hidden-orientation-*.png` figures are complete (600 paired cells):
LER, paired hidden-minus-directed LER, and BP nonconvergence.
`scripts/render_a9_orientation.py` regenerates them from the six audited
checkpoints; `results/a9-figure-inputs.json` records inputs and output hashes.
