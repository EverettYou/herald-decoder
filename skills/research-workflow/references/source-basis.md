# Methodological source basis

These sources support the general workflow. They are starting points; every new
scientific task still requires a domain- and method-specific literature search.

- Gelman et al., [Bayesian Workflow](https://arxiv.org/abs/2011.01808):
  scientific inference includes iterative model construction, computation,
  checking, validation, understanding, and comparison—not merely fitting.
- Gabry et al., [Visualization in Bayesian
  Workflow](https://arxiv.org/abs/1709.01449): visualization is part of model
  building and checking and should expose rather than conceal uncertainty and
  model failures.
- Talts et al., [Validating Bayesian Inference Algorithms with
  Simulation-Based Calibration](https://arxiv.org/abs/1804.06788): complex
  inference implementations should be calibrated against known generative
  truths.
- Morris, White, and Crowther, [Using simulation studies to evaluate statistical
  methods](https://onlinelibrary.wiley.com/doi/10.1002/sim.8086): simulation
  studies require explicit aims, data-generating mechanisms, estimands, methods,
  performance measures, and Monte Carlo uncertainty.
- Kass et al., [Ten Simple Rules for Effective Statistical
  Practice](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1004961):
  begin with the scientific question, justify method choice, examine dependence,
  prefer supported simplicity, and report uncertainty.
- Sandve et al., [Ten Simple Rules for Reproducible Computational
  Research](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1003285):
  retain the production path, raw data behind plots, software versions, seeds,
  and intermediate results.
- Boulesteix, [Ten Simple Rules for Reducing Overoptimistic Reporting in
  Methodological Computational
  Research](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1004191):
  compare methods fairly, document assumptions and limitations, and avoid
  analysis choices that systematically exaggerate performance.
- NIST/SEMATECH, [Nonlinear least-squares
  regression](https://www.itl.nist.gov/div898/handbook/pmd/section1/pmd142.htm),
  and NIST Technical Note 1297, [Guidelines for Evaluating and Expressing
  Uncertainty](https://www.nist.gov/document/tn1297spdf): an uncertainty band
  must correspond to a stated model, procedure, component set, and interval
  meaning; it is not generic visual decoration.

For task-specific research, search outward from the relevant sources for recent
primary work, competing formulations, assumptions, diagnostics, negative
results, and applications in the actual scientific domain. Record what each
source changes in the plan.
